# Как устроена Rada

## Выбор движка распознавания

Перед реализацией проверили, что реально доступно на macOS 27 (M1, 8 ГБ):

| Вариант | Русский офлайн | Пунктуация | Итог |
|---|---|---|---|
| `SpeechTranscriber` (новая модель Apple, macOS 26+) | нет — `ru-RU` отсутствует в `supportedLocales` | — | не подходит |
| `DictationTranscriber` / `SFSpeechRecognizer` on-device | да | **нет**: текст сплошной, даже с опцией `.punctuation` | только как запасной движок |
| Apple Foundation Models (on-device LLM) для расстановки пунктуации | русский не поддерживается | — | не подходит |
| **Whisper Large v3 Turbo** (whisper.cpp + Metal) | да | да: точки, запятые, вопросы, кавычки, регистр | **основной движок** |

Пример на одной и той же записи:

```
Apple:   Вчера министр финансов Антон Зельманов заявил что бюджет не будет пересмотрен однако эксперты…
Whisper: Вчера министр финансов Антон Силуанов заявил, что бюджет не будет пересмотрен. Однако эксперты…
```

### Прямая расшифровка или постобработка записи?

Ни то, ни другое в чистом виде.

- **Посимвольная потоковая расшифровка** даёт текст во время речи, но модель не видит конца фразы и хуже расставляет пунктуацию. Для диктовки показывать промежуточный текст не нужно: он всё равно вставляется после остановки.
- **Расшифровка всей записи после остановки** даёт лучшую пунктуацию, но задержка растёт с длиной диктовки.

Rada использует гибрид: **фоновая расшифровка законченных фраз**. Аудио копится в памяти. Как только набирается 12–28 секунд речи и звучит естественная пауза, этот фрагмент уходит в Whisper целиком, пока вы продолжаете говорить. Модель всегда видит фразы целиком, а следующий фрагмент получает конец предыдущего как контекст. После остановки остаётся расшифровать только последние секунды.

Замер на минутной диктовке (журналистский текст, M1, release-сборка):

| Схема | Задержка после остановки | Качество |
|---|---|---|
| Вся запись после остановки | 7,3 с | эталон |
| **Фоновая расшифровка по паузам (Rada)** | **2,6 с** | то же |

Для борьбы с «галлюцинациями» Whisper на тишине («Продолжение следует…», титры субтитров) используются Silero VAD (тишина вырезается до распознавания) и фильтр известных артефактов.

### Обработка текста

После распознавания текст проходит бережную обработку (`RadaKit/Text`). Она ничего не перефразирует:

1. Удаление известных артефактов Whisper (титры, зацикливание).
2. Голосовые команды: «новый абзац», «новая строка».
3. Словарь: варианты распознавания → правильное написание; восстановление регистра аббревиатур и латиницы (`вшэ` → `ВШЭ`, `iphone` → `iPhone`). Обычные слова не трогаются.
4. Пробелы вокруг знаков препинания, заглавная буква в начале, точка в конце.

Имена, числа, отрицания и цитаты сохраняются, что проверено тестами.

## Архитектура

```
Sources/
├─ CWhisper/            C-модуль whisper.cpp (статическая библиотека с Metal)
├─ RadaKit/             вся логика, без UI
│  ├─ Audio/            AudioCapture (AVAudioEngine → 16 кГц mono), SampleBuffer, ChunkPlanner (паузы)
│  ├─ Transcription/    TranscriptionEngine, WhisperEngine, AppleDictationEngine, ModelInstaller
│  ├─ Dictation/        DictationController (сценарий), DictationSession (фоновые фрагменты)
│  ├─ Text/             TextProcessor: артефакты → команды → словарь → нормализация
│  ├─ Dictionary/       модель и хранилище словаря (JSON)
│  ├─ Insertion/        TextInserter (⌘V + восстановление буфера), контекст курсора (AX)
│  ├─ System/           глобальные клавиши (Carbon), разрешения, автозапуск
│  └─ Settings/         AppSettings (UserDefaults), пути, перечисления
└─ Rada/                приложение (SwiftUI + AppKit)
   ├─ App/              точка входа, AppModel (корень зависимостей)
   ├─ Mascot/           живая сфера: позы, аниматор, рендерер
   ├─ HUD/              плавающий индикатор (NSPanel, Liquid Glass)
   ├─ MenuBar/          меню и значок
   ├─ Settings/         окно настроек: Основные, Распознавание, Словарь, Конфиденциальность
   ├─ Components/       карточки, строки, бейджи, клавиши — в духе shadcn/ui
   └─ Icon/             генерация иконки приложения из маскота
```

Сценарий: `HotkeyCenter` → `DictationController.toggle()` → `AudioCapture` + `DictationSession` (фрагменты → `TranscriptionEngine`) → `TextProcessor` → `TextInserter` → индикатор.

## Ограничения

- Качество проверено на синтезированной речи (голос Milena) и журналистских фразах с именами и числами. Проверка на живом голосе журналистки, в шуме и с акцентами — следующий шаг.
- Только Apple Silicon (сборка arm64, Metal).
- Первые ~0,2 с после нажатия клавиши уходят на запуск микрофона. Начинайте говорить после звукового сигнала.
- Esc перехватывается только во время записи и распознавания.
- Liquid Glass включается на macOS 26+. На macOS 15 используется системный материал.
- «Диктовка Apple» для русского не расставляет пунктуацию: Rada добавляет только заглавную букву и точку в конце.
- macOS 26+ может показывать иконку в стандартной «рамке», так как она собрана без Icon Composer (нужен Xcode).
